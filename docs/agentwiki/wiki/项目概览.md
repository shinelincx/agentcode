# 项目概览

当前仓库包含多 Agent 软件交付体系的评审 HTML、V2.0 历史方案和 V2.1 修订方案。V2.0 已在 2026-11-11 本轮对话全文读取；原评审 HTML 仍仅结构级阅读。V2.1 为待评审提案，尚无平台实现与运行验收证据。

最新综合方案复用 [[wiki/方案演进]]，以该 Markdown 为编辑源生成 HTML 阅读版。修订聚焦执行恢复、预算预占、权限落地、审批绑定、不可变发布及十二项故障验收场景。历史版本与替代原因保留，不把文档升级等同系统升级。

正式需求与任务状态以 GitHub Issues 为准，正式领域及架构决策遵循领域文档与 ADR。当前仓库 Issue 查询为空；本次对话仅授权更新方案文档。
