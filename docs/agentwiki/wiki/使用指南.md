# 使用指南

## 摄取
资料放进 raw/ 后，说：“摄取这份资料，更新 agentwiki，注明来源、冲突和阅读范围。”优先一次一份，核验摘要后继续。

## 问答
说：“根据 agentwiki 分析 V2 的改进，附来源并区分设计与实现；把可复用结论写回知识库。”

## 巡检
说：“巡检 agentwiki 的断链、无来源结论、过期快照与冲突，修复确定问题并记录结果。”

用户选择资料并核验结论，Agent 维护知识与关联。Obsidian 用搜索、反向链接和关系图浏览，不需要额外插件或 API 密钥。Agent 写入的本地文件由 Obsidian 读取；没有配置自动后台摄取。

任务仍在 GitHub Issues；术语及正式决策仍在根 CONTEXT.md 和 docs/adr/。详见 [[AGENTS]]、[[sources/LLM-Wiki]]。返回 [[index]]。
