## 外部一手资料

外部页面通过网页工具在线读取，未保存网页 raw 快照，故不声明网页内容 SHA256。下列摘要限定于已核验的语义；实施仍须锁定实际安装版本并测试。

| 来源 | 已核验内容与定位 | 方案用途 |
| --- | --- | --- |
| [LangGraph Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) | Rules of interrupts：恢复会从节点起点重新执行，中断前副作用需要幂等。 | 第五章恢复协议及 AC-01。 |
| [LangGraph StateGraph 源码](https://github.com/langchain-ai/langgraph/blob/main/libs/langgraph/langgraph/graph/state.py) | add_edge：多个 start 节点需要全部完成；链接为可变 main，未将其当项目锁定版本。 | 删除 V2.0 用 AND 汇合表达成功/失败 OR 路径的骨架。 |
| [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api) | State/Reducers：状态更新需定义合并语义。 | 并行 artifacts 合并规则。 |
| [npm node-semver](https://github.com/npm/node-semver) | Caret/Tilde ranges：^1.2 可接受 minor，~1.2.0 限 patch 范围。 | 第十一章版本策略修正。 |
